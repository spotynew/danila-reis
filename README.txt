SITE DANILA REIS — PRONTO PARA VERCEL

Projeto HTML/CSS/JS estático. Entrada: index.html.

Hospedar com Vercel:
1) Abra https://vercel.com/new
2) Importe um repositório GitHub contendo os arquivos deste diretório na raiz.
3) Em Framework Preset selecione Other (ou mantenha sem framework).
4) Build command: vazio. Output directory: vazio (raiz do projeto).
5) Deploy.

Ou com a CLI da Vercel instalada e autenticada:
   vercel deploy --prod
